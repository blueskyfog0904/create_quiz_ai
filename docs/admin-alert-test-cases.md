# 관리자 화면 알림 — 테스트 케이스

작성: 2026-11-16 · 대상: 알림 종·토스트·소리·메뉴 배지 (커밋 `282ea92`, DB `20261113210000_admin_events`)

서비스는 출시 전입니다. 아래 테스트는 관리자 계정으로 `https://www.summersuninst.com/admin`에 로그인한 상태에서 합니다.

## 테스트 전에

- **판매 중지 버튼은 누르지 않습니다.** 누르면 실제로 충전이 막히고, 다시 켜려면 SQL을 실행해야 합니다.
- 슬랙 웹훅을 아직 등록하지 않았다면 종 안에 "슬랙 알림 미설정"이 보이는 것이 정상입니다.
- 알림은 한 번 생기면 지울 수 없습니다(기록 보존용). 테스트로 만든 알림은 목록에 남습니다.

## 알림을 만드는 방법

| 방법 | 누가 | 만들어지는 알림 | 남는 것 |
|---|---|---|---|
| A. 회원 계정으로 1:1 문의 등록 (`/mypage/support`) | 대표 (테스트 회원 계정) | "새 문의 [분류] 제목" — 소리 있음 | 문의 1건 (관리자 화면에서 답변 처리) |
| B. 테스트 알림을 알림 표에 직접 추가 (SQL) | 개발 담당(Claude) | "테스트 알림 …" — 화면 전용은 소리 없음 | 알림 목록의 테스트 줄 |

가장 실제에 가까운 것은 A입니다. B는 업무 데이터를 건드리지 않고 화면 동작만 볼 때 씁니다.

## 케이스

| 번호 | 확인할 것 | 하는 방법 | 기대 결과 |
|---|---|---|---|
| T1 | 종이 보인다 | `/admin`을 연다 | 사이드바 맨 위(접기 버튼 왼쪽)에 종 모양 버튼. 화면 오류 없음 |
| T2 | 종을 열면 내용이 나온다 | 종을 누른다 | 최근 알림 목록(없으면 없다는 문구), "처리 대기" 6항목과 건수, 슬랙 전송 상태 줄, "소리 켜짐/꺼짐", "브라우저 알림 허용" |
| T3 | 슬랙 전송 상태 | 종을 연 채로 본다 | 웹훅 등록 전: "슬랙 알림 미설정". 등록 뒤: 상태 줄 없음(정상) |
| T4 | 새 알림이 바로 뜬다 (실시간) | 관리자 화면을 띄워 둔 채, 방법 A 또는 B로 알림을 1건 만든다 | 새로고침 없이 1~2초 안에 화면 구석에 토스트("제목", "열기" 버튼). 종에 빨간 숫자 1 |
| T5 | 여러 건은 묶인다 | 5초 안에 알림 3건을 만든다 (방법 B) | 토스트가 3개 쌓이지 않고 하나가 "새 알림 3건"으로 바뀐다. 종 숫자는 3 늘어난다 |
| T6 | 소리 | 화면을 한 번 클릭해 둔 뒤, 소리 나는 알림(방법 A)을 만든다 | 짧은 알림음 1번. 종 안에서 "소리 꺼짐"으로 바꾸면 다음 알림은 무음 |
| T7 | 화면 전용 알림은 조용하다 | 방법 B의 화면 전용 알림을 만든다 | 토스트는 뜨지만 소리는 나지 않는다 |
| T8 | 확인하면 숫자가 사라진다 | 숫자가 붙은 종을 누른다 | 목록 맨 위에 방금 알림. 종의 숫자가 사라진다. 새로고침해도 숫자가 다시 생기지 않는다 |
| T9 | 알림을 누르면 해당 화면으로 간다 | 목록의 알림 한 줄(또는 토스트의 "열기")을 누른다 | 문의 알림 → `/admin/support`, 환불·결제 알림 → `/admin/refunds` |
| T10 | 다른 탭에 있을 때 | 관리자 탭을 두고 다른 탭으로 옮긴 뒤 알림을 만든다 | 관리자 탭 제목 앞에 `(1)`. 탭으로 돌아오면 원래 제목으로 돌아간다 |
| T11 | 브라우저 알림 | 종 안의 "브라우저 알림 허용"을 누르고 허용한다. 다른 탭으로 옮긴 뒤 소리 나는 알림을 만든다 | 컴퓨터 화면 구석에 브라우저 알림. 허용을 누르기 전에는 권한을 묻는 창이 저절로 뜨지 않는다 |
| T12 | 메뉴 배지 | 답변 대기 문의가 1건 있는 상태에서 사이드바를 본다 | "문의" 메뉴 옆에 숫자 1. 답변을 마치면 사라진다. 환불 메뉴도 대기 건이 있으면 숫자 |
| T13 | 처리 대기 숫자가 대시보드와 같다 | 종 안의 "처리 대기" 숫자와 `/admin` 대시보드의 숫자를 비교한다 | 6항목 모두 같다 |
| T14 | 휴대폰 화면 | 휴대폰(또는 좁은 창)에서 `/admin`을 연다 | 메뉴 버튼 옆에 종. 눌러서 내용이 화면 안에 다 보인다 |
| T15 | 다른 관리자 화면에서도 | `/admin/refunds`, `/admin/support`, `/admin/credits`로 옮겨 다닌다 | 어느 화면에서나 종이 있고, 옮겨도 숫자가 유지된다 |
| T16 | 연결이 끊겼을 때 | 관리자 화면을 띄운 채 인터넷을 30초쯤 끊었다 다시 연결한다 | 끊긴 동안 종 옆에 "실시간 연결 끊김". 다시 연결되면 표시가 사라지고, 그 사이 생긴 알림이 반영된다 |
| T17 | 일반 회원에게는 안 보인다 | 일반 회원 계정으로 사이트를 쓴다 | 관리자 알림은 어디에도 보이지 않는다(관리자 화면 자체에 들어갈 수 없음) |
