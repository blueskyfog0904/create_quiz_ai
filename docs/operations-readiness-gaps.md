## 3. 이 규모(대표 1 + CS 1)에는 과한 것

- **쿠폰·프로모션 코드:** 결제 정합성 검증 범위가 커집니다. 요금제 보너스와 크레딧 지급으로 대신합니다.
- **휴면 회원 처리:** 2023년 개정으로 의무가 아닌 것으로 알려져 있습니다(확인 필요).
- **부분 환불:** 정책이 "미사용 전액"입니다.
- **판매 예약, 여러 상품 묶음 할인**
- **구매자별 파일 워터마크:** PDF만 가능하고 HWP·ZIP은 불가하며 비용이 듭니다.
- **계정 공유 자동 탐지, 1기기 로그인 제한:** 교사는 집과 학교 PC를 함께 씁니다.
- **전체 CSP, 별도 스테이징 환경, 전 API 레이트 리밋 인프라, APM, 전용 CDN, 퍼널 전용 분석 도구**
- **이벤트 크레딧 일괄 지급·가입 축하 크레딧·할인 기간:** 첫 이벤트를 하기로 정했을 때 만듭니다.
- **회원 엑셀 내보내기:** 마케팅 발송을 시작할 때 만듭니다.

## 4. 전문가 확인 권장

**변호사**
- 교과서·EBS·평가원 기출·영어 원문 지문을 쓴 변형문제를 유료로 판매하는 것이 적법한지, 필요한 이용허락 범위
- 충전 크레딧 정책이 유효한지: 7일 전액 미사용만 환불, 일부 사용 시 잔액 환불 불가, 1년 소멸
- 미성년자 결제를 취소할 때 돌려줘야 하는 범위, 14세 미만 정책
- 디지털 자료 청약철회 제한이 성립하는 요건, "받지 않은 자료 30일 환불" 문구
- 결제 회원 탈퇴 시 남길 항목과 기간
- 처리방침의 위탁·국외 이전 문구, 이 규모에 적용되는 안전조치의 범위
- 크레딧이 선불전자지급수단 규제 대상인지

**세무사**
- 크레딧 부가세 과세 시점(충전 때와 사용 때 중 언제인지)
- 소멸 크레딧과 무상 지급 크레딧의 처리
- 카드 결제 건에 세금계산서를 요청받았을 때의 대응(매출전표로 대체 가능한지)

## 5. 대표 결정이 필요한 것

1. **14세 미만:** 가입 불가(추천) 또는 법정대리인 동의(본인인증 필요, 작업량 큼) 중 하나

5. **결제 회원 탈퇴:** 익명화 방식으로 진행할지. 남길 항목과 기간은 변호사 확인 뒤 확정

## 6. 대표 결정 (2026-11-20)

- **0-1 복구 코드 파일:** 대표가 삭제했습니다(확인함).
- **0-2 2단계 인증, 0-3 하단 이메일, 0-5 Pro 전환:** 출시할 때 처리합니다. 목록은 `docs/launch-owner-todo.md`에 있습니다.
- **14세 미만:** 가입할 수 없습니다. 가입 동의에 "만 14세 이상입니다(필수)"를 넣고, 약관에도 적습니다.
- **구매 자료 이용 범위:** 구매자 본인의 수업용 인쇄·배포는 허용합니다. 파일 공유, 재판매, 온라인 게시는 금지합니다.
- **CAPTCHA:** **이메일 가입**에만 적용합니다.
  - Supabase 설정에서 CAPTCHA를 켜면 로그인과 비밀번호 재설정에도 함께 걸립니다. 그래서 Supabase 설정은 켜지 않습니다.
  - 대신 이메일 가입 서버 처리에서 사이트가 직접 확인합니다(예: Cloudflare Turnstile 무료).
  - 키 발급은 대표가 직접 합니다.
- **결제 회원 탈퇴:** 개인정보는 지우고 결제·주문 기록만 남기는 익명화 방식으로 합니다.
  - 남길 항목과 기간은 변호사 확인 뒤 확정합니다.
  - 결제 영역이라 검증 3명을 거칩니다.
