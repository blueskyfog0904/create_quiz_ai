## 4. 결제 경로 캡처 순서

1. `/pricing`에서 충전 상품과 정책을 확인한다.
2. `충전하기`를 선택한다.
3. `/checkout`에서 주문금액, 사용기간, 환불 조건과 결제수단을 확인한다.
4. 허용된 수단으로 결제를 완료한다.
5. 성공 화면과 `/mypage/payments`의 주문·결제 상태를 확인한다.
6. `/mypage/credits`에서 충전 source, 만료일, 환불 마감일을 확인한다.
7. 실제 사용처에서 일부 또는 전부 사용하고 transaction을 확인한다.

## 5. 환불 경로 캡처 순서

1. 완전 미사용 충전 source의 환불 가능 상태와 마감일을 확인한다.
2. 환불정책 링크를 연다.
3. 환불 요청을 생성한다.
4. 관리자에서 요청을 검토하고 Toss 원 결제수단 취소를 수행한다.
5. 관리자 화면에서 cancel transaction key와 완료 시각을 확인한다.
6. 사용자 결제내역과 크레딧 화면에서 환불 완료 및 source 동결·차감을 확인한다.
7. 일부 사용, 7일 초과, 만료 source의 요청이 거부되는 화면을 별도 보관한다.

## 6. Toss 관리자·운영 증빙

다음 자료는 외부 공개 화면이 아니라 내부 감사 자료로 보관한다.

- 포인트 충전 전용 MID와 결제위젯 variant
- 활성 결제수단 목록
- 계좌이체·가상계좌·휴대폰·상품권·해외결제 비활성 상태
- 하나카드 제한 설정 또는 Toss 서면 답변
- 간편결제 연결 계좌·머니·카드 제한에 관한 Toss 서면 답변
- test 결제·전액 취소 결과
- 운영 소액 결제·즉시 전액 취소 결과가 필요한 경우 승인 기록
- 웹훅 등록 상태. URL token은 마스킹한다.
- 정기 대사 최근 성공 시각과 불일치 0건 결과

## 7. 최종 서명 gate
