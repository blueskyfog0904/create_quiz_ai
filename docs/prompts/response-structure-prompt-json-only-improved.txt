【출력 형식 지시】
- 반드시 하나의 문제만 생성하세요. 배열이 아닌 단일 JSON 객체 하나만 반환하세요.
- 최종 응답은 순수 JSON만 포함해야 합니다.
- 최종 응답의 첫 글자는 반드시 { 이고, 마지막 글자는 반드시 } 이어야 합니다.
- JSON 객체 앞뒤에 어떤 설명, 인사말, 요약, 주석, 머리말, 꼬리말도 붙이지 마세요.
- 마크다운 포맷을 사용하지 마세요. 백틱 3개로 감싸는 코드블록, json 언어 표시, 일반 텍스트 설명을 절대 포함하지 마세요.
- JSON 외 문자가 한 글자라도 포함되면 실패로 간주됩니다.
- 아래의 JSON 구조만 사용하세요. 아래에 명시되지 않은 추가 필드는 포함하지 마세요.
- 모든 key는 반드시 큰따옴표를 사용하세요.
- 문자열 값은 반드시 큰따옴표를 사용하세요.
- JSON 문자열 내부 줄바꿈은 반드시 \n 으로 이스케이프하세요. 문자열 안에 실제 줄바꿈 문자를 넣지 마세요.
- trailing comma를 사용하지 마세요.
- 값이 없는 선택 필드는 생략하지 말고 null로 반환하세요.
- 선택지 label은 반드시 ①, ②, ③, ④, ⑤ 중 하나를 사용하세요.

응답 형식 (단일 문제):

{
  "question_text": "문항(문제의 질문 / 문제의 번호는 포함되면 안됨)",
  "question_text_forward": "passage_text 앞에 표시될 별도의 지문 (선택사항, 없으면 null)",
  "question_text_backward": "passage_text 뒤에 표시될 별도의 지문 (A),(B),(C) (선택사항, 없으면 null)",
  "passage_text": "(question_text 다음에 나오는) 영어지문 텍스트 (필수 값)",
  "choices": [
    { "label": "①", "text": "첫 번째 선택지 내용" },
    { "label": "②", "text": "두 번째 선택지 내용" },
    { "label": "③", "text": "세 번째 선택지 내용" },
    { "label": "④", "text": "네 번째 선택지 내용" },
    { "label": "⑤", "text": "다섯 번째 선택지 내용" }
  ],
  "answer": "정답 (예: ①, ②, ③, ④, ⑤)",
  "explanation": "정답 해설 (선택사항, 없으면 null)",
  "difficulty": "난이도 (Low, Medium, High 중 하나 / 없으면 null)",
  "grade_level": "학년 (예: Middle1, Middle2, Middle3, High1, High2, High3 / 없으면 null)"
}

---
choices 필드 규칙:

1. 선택지에 별도 텍스트가 있는 경우:
   "choices": [
     { "label": "①", "text": "선택지 내용 A" },
     { "label": "②", "text": "선택지 내용 B" },
     { "label": "③", "text": "선택지 내용 C" },
     { "label": "④", "text": "선택지 내용 D" },
     { "label": "⑤", "text": "선택지 내용 E" }
   ]

2. 선택지가 숫자만 있고, 선택지 내용이 question_text에 포함된 경우:
   "choices": []

---
필드 설명:

| 필드 | 필수 | 타입 | 설명 |
|-----|-----|-----|-----|
| question_text | O | string | 문항(문제의 질문 / 문제의 번호는 포함되면 안됨) |
| question_text_forward | X | string/null | 지문(passage_text) 앞에 표시될 별도 텍스트 |
| question_text_backward | X | string/null | 지문(passage_text) 뒤에 표시될 별도 텍스트 |
| passage_text | O | string | (question_text 다음에 나오는) 영어지문 텍스트 (필수) |
| choices | O | array | 선택지 배열. 선택지 내용이 question_text에 포함된 경우 빈 배열 가능 |
| answer | O | string | 정답 |
| explanation | X | string/null | 해설. 없으면 null |
| difficulty | X | string/null | 난이도. Low, Medium, High 중 하나. 없으면 null |
| grade_level | X | string/null | 학년. Middle1, Middle2, Middle3, High1, High2, High3 중 하나. 없으면 null |

---
최종 자체 점검 후 출력하세요:

1. 응답 전체가 단일 JSON 객체인가?
2. 응답 첫 글자가 { 이고 마지막 글자가 } 인가?
3. 코드블록, 백틱, json 언어 표시, 설명 문장, 주석이 전혀 없는가?
4. 필드명이 지정된 구조와 정확히 일치하는가?
5. JSON.parse로 바로 파싱 가능한 유효한 JSON인가?

위 조건을 모두 만족한 경우에만 최종 응답을 출력하세요.
