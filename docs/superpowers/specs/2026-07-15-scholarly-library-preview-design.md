# Scholarly Library 프리뷰 디자인

## 목표

기존 메인 페이지와 공통 레이아웃을 수정하지 않고, `써머썬 연구소`의 두 대표 서비스인 AI 영어문제 생성과 문제마켓을 동등하게 설명하는 학술 아카이브형 메인 페이지를 별도 URL에서 검토할 수 있게 한다.

## 승인된 방향

- 콘셉트: B안 `Scholarly Library`
- 경로: `/preview/scholarly-library`
- 대상: 영어·국어 수업 자료를 만들고 축적하는 교사와 학원 강사
- 인상: 신뢰도 높은 연구소, 정돈된 자료실, 실용적인 시험 제작 도구

## 핵심 서비스 구조

### AI 영어문제 생성

- 현재 영어에서만 사용할 수 있으며 국어 AI 생성은 제공하지 않는다.
- 지문 등록/OCR, 문제 유형 선택, AI 생성, 검토와 저장, 시험지 제작 흐름을 보여준다.
- 직접 자신의 지문과 목적에 맞는 문제를 만들고 싶은 사용자를 위한 서비스로 설명한다.

### 문제마켓

- 영어와 국어 모두에서 사용할 수 있는 서비스로 설명한다.
- 내신 문제 전문가가 제작한 문제지를 탐색하고 구매하는 가치가 전면에 보여야 한다.
- 무료 샘플 확인, 개별 자료 선택 구매, 전체 패키지 구매, PDF/HWP 다운로드와 구매자료 보관 흐름을 안내한다.

## 시각 체계

- 배경: Porcelain `#f7f5ef`, Paper `#fffdf8`
- 주색: Archive Green `#245b4e`
- 보조색: Oxford Blue `#1e3a5f`
- 강조색: Brass `#b7791f`
- 제목은 serif 계열, UI와 본문은 기존 sans 계열을 사용한다.
- 카드에는 얇은 테두리, 작은 분류 라벨, 절제된 그림자를 사용한다.

## 페이지 구조

1. 독립 헤더: 브랜드명, 두 대표 서비스 이동, 영어·국어 워크스페이스 진입
2. 히어로: 직접 만드는 AI 영어문제와 전문가 자료를 고르는 문제마켓의 이중 가치 제안
3. 두 대표 서비스: AI 영어문제 생성과 문제마켓을 같은 비중의 대형 카드로 비교
4. AI 영어문제 생성 흐름: 지문 준비 → AI 생성 → 검토·저장 → 시험지 제작
5. 문제마켓 구매 흐름: 전문가 자료 탐색 → 무료 샘플 → 개별/전체 구매 → 라이브러리 보관
6. 과목별 진입: 영어는 AI 생성과 문제마켓, 국어는 현재 문제마켓 중심임을 명시
7. 최종 CTA 및 독립 프리뷰 고지

## 격리 원칙

- 기존 `src/app/page.tsx`와 랜딩 컴포넌트를 수정하지 않는다.
- 기존 글로벌 토큰을 변경하지 않는다.
- 신규 라우트와 신규 프리뷰 컴포넌트만 추가한다.
- 데이터베이스나 인증 상태에 의존하지 않는 Server Component로 만든다.
- CTA만 기존의 실제 영어 AI 생성, 영어 문제마켓, 국어 문제마켓 경로로 연결한다.

## 검증 기준

- `/preview/scholarly-library`가 빌드 가능한 정적 라우트여야 한다.
- 모바일·태블릿·데스크톱에서 주요 섹션이 깨지지 않아야 한다.
- 기존 메인 페이지 관련 파일의 diff가 없어야 한다.
- CTA가 영어 AI 생성, 영어 문제마켓, 국어 문제마켓과 구매 문항 관리의 실제 경로를 가리켜야 한다.
