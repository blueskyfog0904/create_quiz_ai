# Scholarly Library 프리뷰 디자인

## 목표

기존 메인 페이지와 공통 레이아웃을 수정하지 않고, `써머썬 연구소`에 어울리는 학술 아카이브형 메인 페이지를 별도 URL에서 검토할 수 있게 한다.

## 승인된 방향

- 콘셉트: B안 `Scholarly Library`
- 경로: `/preview/scholarly-library`
- 대상: 영어·국어 수업 자료를 만들고 축적하는 교사와 학원 강사
- 인상: 신뢰도 높은 연구소, 정돈된 자료실, 실용적인 시험 제작 도구

## 시각 체계

- 배경: Porcelain `#f7f5ef`, Paper `#fffdf8`
- 주색: Archive Green `#245b4e`
- 보조색: Oxford Blue `#1e3a5f`
- 강조색: Brass `#b7791f`
- 제목은 serif 계열, UI와 본문은 기존 sans 계열을 사용한다.
- 카드에는 얇은 테두리, 작은 분류 라벨, 절제된 그림자를 사용한다.

## 페이지 구조

1. 독립 헤더: 브랜드명, 페이지 내 섹션 이동, 기존 영어 워크스페이스 진입
2. 히어로: 서비스 가치 제안과 대표 CTA, 자료 아카이브 미리보기
3. 핵심 가치: 지문·문항·시험지를 한 흐름으로 연결하는 이유
4. 기능 아카이브: 지문 등록/OCR, AI 문제 생성, 문항 관리, 시험지 제작
5. 제작 흐름: 자료 준비 → AI 생성 → 검토·축적 → 출력
6. 결과물 강조: PDF, Word, HWPX와 영어·국어 워크스페이스
7. 최종 CTA 및 독립 프리뷰 고지

## 격리 원칙

- 기존 `src/app/page.tsx`와 랜딩 컴포넌트를 수정하지 않는다.
- 기존 글로벌 토큰을 변경하지 않는다.
- 신규 라우트와 신규 프리뷰 컴포넌트만 추가한다.
- 데이터베이스나 인증 상태에 의존하지 않는 Server Component로 만든다.
- CTA만 기존의 실제 영어 워크스페이스 경로로 연결한다.

## 검증 기준

- `/preview/scholarly-library`가 빌드 가능한 정적 라우트여야 한다.
- 모바일·태블릿·데스크톱에서 주요 섹션이 깨지지 않아야 한다.
- 기존 메인 페이지 관련 파일의 diff가 없어야 한다.
- CTA가 문제 생성, 문항 관리, 시험지 보관함의 실제 경로를 가리켜야 한다.
