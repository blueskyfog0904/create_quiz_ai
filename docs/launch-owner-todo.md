# 출시할 때 대표가 할 일 목록

작성일: 2026-11-20
**지금은 운영 준비 단계입니다.** 아래는 대표가 "운영을 시작할 때 하겠다"고 미룬 일들을 한곳에 모은 것입니다. 출시를 준비할 때 Claude가 이 목록을 다시 꺼내 함께 확인합니다.

## 1. 계정·보안
- [ ] Supabase·Vercel·페이앱·GitHub 계정 **2단계 인증** 켜기
- [ ] 관리자 사이트 대표 계정 2단계 인증(기능을 만든 뒤 켜기)
- [ ] 관리자 계정 정리
  - admin01~03의 대표 권한 낮추기·정리
  - admin04(시험용 직원 계정) 비밀번호 변경 또는 삭제
- [ ] 이메일 가입 CAPTCHA 키 발급(Cloudflare Turnstile 등). 기능을 만들 때 안내합니다

## 2. 요금제·인프라
- [ ] **Vercel Hobby → Pro 전환**: Hobby는 상업 이용이 제한됩니다. 로그 보존과 배포 되돌리기 제약도 함께 풀립니다
- [ ] **Supabase 무료 → Pro 전환**
  - 일일 자동 백업이 생깁니다.
  - 지금은 다른 프로젝트(`office_restaurant`) 때문에 무료 한도가 초과된 상태입니다.
- [ ] 판매 파일 백업 첫 실행과 복구 리허설 1회(백업 스크립트는 운영 준비 때 만듭니다)

## 3. 사이트 정보·약관
- [ ] 하단 정보 **상담/주문 이메일** 채우기(저작권 신고 창구로도 씁니다)
- [ ] 개정한 약관·처리방침의 시행일 확정, 보호책임자 이름·직책·연락처 확정
- [ ] **마케팅 수신 동의** 세부 내용은 클라이언트와 상의해 정하기

## 4. 결제·판매
- [ ] 충전 상품 이름·설명 다듬기, **test 요금제(1,000원) 판매 중지·정리**
- [ ] 페이앱 **영수증(매출전표) 발급 메뉴**를 직접 확인하고 런북 RB-5 채우기
- [ ] 페이앱 공용 계정의 사이트 밖 결제 통보 경보 정리(`docs/admin-deferred-checklist.md` 참고)
- [ ] 충전 판매 켜기(판매 상태 확인)

## 5. 데이터 정리
- [ ] **문제마켓 상품 전체 재정리**
  - 재정리하면서 "구매할 수 없는 상품이 공개되는 길 막기"(관리자 UI 계획 1차-가)도 함께 처리합니다.
  - 상품별 원저작물 "이용 근거"를 기록합니다.
- [ ] **테스트 계정·테스트 주문·테스트 문의 삭제**
- [ ] 문의 카테고리 추가: "자료 요청", "개인정보 열람·삭제 요청", "권리침해 신고"(DB)

## 6. 전문가 확인 (`docs/operations-readiness-gaps.md` 4절)
- [ ] **변호사**
  - 교과서·EBS·기출·영어 지문을 쓴 변형문제를 유료로 파는 것이 적법한지
  - 크레딧 환불·소멸 정책이 유효한지
  - 미성년자 결제를 취소할 때 돌려줄 범위
  - 결제 회원 탈퇴 시 남길 항목과 기간
- [ ] **세무사**
  - 크레딧 부가세를 언제 과세하는지
  - 소멸·무상 크레딧 처리
  - 세금계산서 요청 대응

## 7. 출시 직전 확인
- [ ] 이메일로 새로 가입해 보고 가입 인증 메일과 비밀번호 재설정 메일이 오는지 확인
- [ ] 전체 화면을 운영 주소에서 한 번씩 확인(결제 1건 실결제 → 환불 시험 포함)
