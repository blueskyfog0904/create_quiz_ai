# 런북 1 — 미성년자 결제 취소 (충전 크레딧)

- 작성일: 2026-11-23 · 9번 묶음(계획 `docs/plan-bundle9-payment-refund-notice.md`, 문구 `docs/bundle9-copy-draft.md` F1)
- 서비스 상태: **출시 전**. 출시 뒤에 쓸 절차를 미리 적은 문서입니다.
- 읽는 사람: 대표·CS 담당. 근거 조항: 취소·환불정책 7절, 이용약관 '미성년자' 조항(민법 5조).
- 공통 보류·해제 방법(PG 로 취소할 수 없을 때 쓰는 SQL 템플릿)은 [런북 3의 0절](point-charge-3-reissued-credit-cancellation.md#0-공통-사용-보류-수단)에 있습니다.

## 언제 쓰나
만 19세 미만 회원 본인 또는 법정대리인이 "동의 없이 결제했다"며 충전 결제 취소를 요청할 때. **기간(7일)·사용 여부와 상관없이** 받습니다. 만 14세 체크만으로 거절하지 않습니다.

## 취소할 수 없는 경우(대표가 판단, 근거를 적어 둠)
- 법정대리인이 쓰도록 허락한 돈(용돈 등) 범위 안의 결제
- 회원이 속임수로 성인이라고 믿게 했거나, 법정대리인 동의가 있는 것처럼 믿게 한 경우
- 판단이 애매하면 변호사 확인 목록(`docs/launch-owner-todo.md`)에 올리고, 그동안은 아래 0단계 보류만 해 둡니다.

## 순서

### 1. 접수·확인
1. 고객센터(1:1 문의·이메일·전화)로 받은 시각을 기록합니다(문의 작성 시각·메일 수신 시각·통화 시각).
2. 본인 요청: 나이를 확인할 자료(주민등록번호 뒷자리 가림). 법정대리인 요청: 관계를 확인할 자료(가족관계증명서 등, 뒷자리 가림).
3. 관리자 화면 `/admin/users/<회원>` 에서 해당 결제(주문번호)와 그 결제로 받은 크레딧을 확인합니다.

### 2. PG 로 취소할 수 있을 때(보통)
1. **바로 페이앱 콘솔에서 전취소**합니다(이것이 사용 보류입니다). 취소 통보가 오면 사이트가 자동으로 원래 크레딧과, 그 결제에서 비롯해 자료 환불로 다시 지급한 크레딧까지 함께 사용 보류합니다(경보 `REISSUED_CREDIT_HELD` 가 뜰 수 있음 — 정상).
2. `/admin/refunds` 의 '수동 확인' 목록에 이 결제가 뜹니다. 수동 완료 화면에서 원천별 원자료(처음 지급·남은 양·쓸 수 있는 몫·만료·사용 합)를 확인합니다.
3. 수동 완료: 처리 방식 '페이앱 취소 요청', 환불 금액 = 결제 금액 전액, **전액 모드**(화면이 미리보기의 쓸 수 있는 몫 합을 그대로 보냄).
4. 회원이 "받은 이익이 남아 있는 한도에서 돌려줄" 몫(이미 쓴 크레딧으로 받은 자료 등)은 **변호사 확인 전까지 대표가 건별 판단**하고, 근거를 수동 완료 메모에 적습니다.
5. 회원 안내: 취소 완료·카드사 반영 기간(영업일 2~5일)·회수한 크레딧.

### 3. PG 로 취소할 수 없을 때(휴대폰 결제 당월 경과 등)
1. 대표 승인 뒤 **보류 템플릿**(`supabase/scripts/bundle9_point_charge_hold.sql`)을 SQL 편집기에서 실행합니다 — 환불 요청이 없으면 새로 만들고, 원래 크레딧과 다시 지급한 크레딧을 함께 보류합니다(런북 3 0절).
2. 돌려줄 금액 계산·근거 기록(전액이 원칙, 받은 이익 범위는 위 2-4와 같음).
3. 회원 본인 명의 계좌 정보를 받고, **받은 날부터 3영업일 안에** 송금합니다(늦어지면 지연배상 — 취소·환불정책 5절).
4. 수동 완료: 처리 방식 '계좌 송금(bank_transfer)', 전액 모드, 환불 금액 = 실제 송금액.
5. 계좌 정보는 송금 확인 뒤 바로 파기(문의 첨부·메일 삭제)합니다.

## 하지 말 것
- 판정 화면(크레딧 화면)의 '기간 지남'·'이미 사용' 표시를 이유로 거절하지 않습니다 — 그 판정은 단순 변심용입니다.
- 크레딧을 SQL 로 직접 고치지 않습니다(수동 완료만 원장·잔액·감사 기록을 함께 남깁니다).
